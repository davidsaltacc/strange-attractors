Particle Count

How many particles will be sent out. The more particles, the more detailed and clean, but also the brighter it will appear. Think of it like the shutter speed of a camera.

Particle Iterations

Literally does the sam thing as the particle count value. More iterations, more detail, more brightness. Think of it like the shutter speed of a camera too.

Discard first X iterations

Instead of using all iterations, the first few should be discarded. This is, because all particles start off completely randomly before falling into the shape of the attractor after a few iterations.

Particle Intensity

How much a single particle will be valued when coloring the attractor. Higher values will mean a bright image, but more noise. Think of it like the ISO of a camera.
