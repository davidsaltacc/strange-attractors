Particle Count

How many particles will be sent out. The more particles, the more detailed and clean, but also the brighter it will appear. Think of it like the shutter speed of a camera.

Particle Count

Particle Iterations

Does the same thing as the particle count value. More iterations, more detail, more brightness. Think of it like the shutter speed of a camera too. Higher values paired with higher discard counts may be neccessary for some attractors to appear properly.

Particle Iterations

Discard first X iterations

Instead of using all iterations, the first few can be discarded. This is because all particles start in random positions instead of the shape of the attractor.

Discard first

Particle Intensity

How much a single particle will be valued when coloring the attractor. Higher values will mean a bright image, but more noise. Think of it like the ISO of a camera.
